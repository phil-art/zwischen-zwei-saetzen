Diese Website ist ein nicht-kommerzielles, statisches Projekt. Sie enthält keine Analyse- oder Werbedienste und keine eingebetteten Inhalte externer Anbieter.

Die für diese Website verantwortliche Person sowie die Kontaktmöglichkeiten sind im Impressum angegeben.

2. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst von GitHub. Beim Aufruf einer GitHub-Pages-Website wird nach Angaben von GitHub die IP-Adresse der besuchenden Person zu Sicherheitszwecken protokolliert und gespeichert. Im Rahmen der technischen Bereitstellung können außerdem übliche Verbindungs- und Nutzungsdaten verarbeitet werden.

Soweit diese Verarbeitung in unserem Verantwortungsbereich erfolgt, dient sie der sicheren und stabilen Bereitstellung dieser nicht-kommerziellen Website und beruht auf Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in der technisch zuverlässigen und sicheren Veröffentlichung des Projekts.

GitHub verarbeitet personenbezogene Daten nach eigenen Angaben auch in den Vereinigten Staaten und weiteren Ländern. GitHub verweist für internationale Datenübermittlungen unter anderem auf Standardvertragsklauseln der Europäischen Kommission und auf seine Teilnahme am EU-U.S. Data Privacy Framework. Weitere Informationen finden sich in der Datenschutzerklärung von GitHub.

3. Freiwillige Speicherung auf deinem Gerät

Die Website bietet die freiwillige Funktion „Auswahl auf diesem Gerät speichern“. Erst wenn du diese Funktion aktivierst, werden ausgewählte Einstellungen im lokalen Speicher deines Browsers (Local Storage) abgelegt. Gespeichert werden die Etappe sowie die gewählten Angaben zu Thema, Perspektive und Ziel. Angaben zu Mitwirkung, Sorge oder Handlungen werden dabei nicht gespeichert.

Diese Daten verbleiben nach dem derzeitigen technischen Stand auf deinem Gerät und werden von dieser Website nicht an den Betreiber übertragen. Du kannst die Speicherung jederzeit über „Gespeicherte Auswahl löschen“ beenden; alternativ kannst du die Website-Daten in deinem Browser löschen.

Die lokale Speicherung wird ausschließlich verwendet, um die von dir ausdrücklich gewählte Speicherfunktion bereitzustellen. Sie ist nicht für Werbung, Reichweitenmessung oder Profilbildung bestimmt.

4. Keine Analyse, Werbung oder externen Einbettungen

Der von uns bereitgestellte Website-Code setzt keine Analyse- oder Werbetracker ein und bindet keine externen Schriftarten, Videos, Social-Media-Plugins oder vergleichbaren Drittinhalte ein. Die Seite enthält lediglich Verweise auf externe Seiten. Erst wenn du einen solchen Link aufrufst, wird eine Verbindung zur jeweiligen Zielseite hergestellt.
